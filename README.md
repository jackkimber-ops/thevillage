# The Village booking system

Booking system for The Village - Family Club, Saigon. **Status: design phase, no app code yet.**

- `CLAUDE.md`: project rules and tech stack
- `PROGRESS.md`: what's done, what's next, what's waiting on the owners
- `docs/open-questions.md`: questions for the owners
- `docs/owner-checklist.md`: accounts and purchases only the owners can make
- `docs/requirements/`: the brief (requirements + developer notes)
- `design/`: wireframes and design files (`design/reference/` holds the original sketches)
